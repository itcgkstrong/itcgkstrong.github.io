Client details are confidential, so these examples are anonymized.

One-click release automation

For a provincial government financial data warehouse, we replaced a multi-person manual release process with an automated pipeline using Jenkins and GitHub Actions. One person can now release reports, applications and database changes across delivery, test and production databases in a single step. This removed the multi-week scheduling lead time and cut emergency-fix turnaround from multiple days to a single afternoon.

Data feed migration to a REST API

We moved a PeopleSoft data feed from a direct Oracle database extract to REST access with JWT authentication against a cloud-hosted source on Oracle Cloud Infrastructure. We developed the PL/SQL components that handled the REST layer and isolated the change from other components.
